# NEON STRIKE

一款純瀏覽器 3D 第一人稱射擊遊戲。玩家可在海岸訓練場移動、瞄準並擊敗持續來襲的機器人敵人。

## 操作

- `W` / `A` / `S` / `D`：移動
- `滑鼠`：瞄準
- `滑鼠左鍵`：射擊
- `R`：裝填
- `Shift`：衝刺
- `Esc`：釋放滑鼠

## 執行

使用本地伺服器開啟，例如：

```powershell
python -m http.server 8080
```

然後瀏覽 `http://localhost:8080`。

## 功能

- 第一人稱 Pointer Lock 控制
- 角色移動與簡易碰撞
- 機器人敵人追擊與近距攻擊
- 射擊、命中、擊殺與波次系統
- 生命值、彈藥、裝填與遊戲結束畫面
- 使用 `assets/map.jpg` 作為海岸地面材質
- 槍械使用 Three.js 幾何零件組成，槍口朝向遊戲前方
